# KTX-Site

Fichiers de la page d’accueil de ktxautomotive.com, chargés par le composant Framer KTXSite.

- `home/fragment.html` : contenu de la page
- `home/home.css` : styles, limités à `#ktxc`
- `home/home.js` : animations, film et voix (`window.KTXC_init(root, base, lang)`)
- `home/assets/` : photos, logo et voix (FR et EN, voix Amélie)

Servi par jsDelivr : `https://cdn.jsdelivr.net/gh/KTX-automotive/KTX-Site@<commit>/home/`
